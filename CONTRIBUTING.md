# Contributing to Awesome AI Security Tools

Thanks for contributing. This list aims to be the most useful, up-to-date reference for AI-powered security tools.

## Adding a Tool

1. Fork the repo
2. Add your tool to the correct category in `README.md`
3. Use this format exactly:

```
| **[Tool Name](https://github.com/owner/repo)** | One-line description of what it does | `python3 tool.py --example command` |
```

4. Submit a pull request with the title: `Add: Tool Name`

## Criteria

A tool belongs on this list if it meets **at least one** of:

- Uses AI/ML as a core component (not just a wrapper)
- Actively maintained (commit in last 12 months)
- Has a working usage example
- Solves a real security problem

## Categories

Pick the most specific category. If a tool fits multiple, put it in the primary one and mention secondary use in the description.

## What Not to Add

- Abandoned projects (no activity > 2 years)
- Generic LLM wrappers with no security focus
- Commercial tools with no free tier or open-source component
- Duplicate tools that don't add something new

## Updating Existing Entries

If a tool has changed its usage, been renamed, or moved repos — PRs to update are very welcome.
